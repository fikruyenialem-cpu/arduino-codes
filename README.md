# Arduino Codes

A collection of Arduino sketches developed while learning and practicing embedded systems programming with Arduino.

## 📌 About This Repository

This repository contains short, focused Arduino programs. Each sketch demonstrates a specific function or concept, making it easier to understand Arduino programming step by step.


## 🛠️ Requirements

- Arduino Uno or a compatible Arduino board
- Arduino IDE
- USB cable for programming the board
- Basic electronic components, depending on the sketch

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the `.ino` file you want to explore in the Arduino IDE.
3. Connect your Arduino board to your computer.
4. Select the correct board and port.
5. Upload the sketch to your Arduino.
6. Observe the result.

**Note:** Some sketches may require additional hardware or software to function correctly.

## 🎯 Learning Goals

- Understand basic Arduino syntax.
- Learn digital input and output.
- Control LEDs and other electronic components.
- Practice serial communication.
- Build a foundation in embedded systems and electronics.
